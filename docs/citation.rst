Citation
========

If you use tacular in research, cite the archived software release. The DOI
`10.5281/zenodo.18475556 <https://doi.org/10.5281/zenodo.18475556>`_ covers all
versions. Each release also receives a version-specific DOI from Zenodo.

The repository's
`CITATION.cff <https://github.com/tacular-omics/tacular/blob/main/CITATION.cff>`_
file holds machine-readable citation metadata. GitHub's **Cite this repository**
menu renders it as APA or BibTeX.

tacular redistributes snapshots of UNIMOD, PSI-MOD, RESID, XLMOD, GNOme and
UniProt PTM data. If your results depend on a specific ontology, cite that
resource as well.
