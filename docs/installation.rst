Installation
============

Requirements
------------

* Python 3.12 or higher
* No runtime dependencies

Install from PyPI
-----------------

.. code-block:: bash

   pip install tacular

This also installs the ``tacular`` command-line tool for refreshing the
ontology data (see :doc:`cli`).

Install from source
-------------------

.. code-block:: bash

   git clone https://github.com/tacular-omics/tacular.git
   cd tacular
   pip install -e .

Using uv (recommended for development)
--------------------------------------

.. code-block:: bash

   git clone https://github.com/tacular-omics/tacular.git
   cd tacular
   uv sync
